## Projects

### [OA Approval AI Agent](https://github.com/Hydra0529/OA-Approval-Agent)

Reads policy PDFs and builds a portfolio, a department calendar, an SLA timeline, and a BPMN diagram for each request. FastAPI and React. The path and the due date come from a deterministic engine. The model reads documents and writes the explanation.

从制度 PDF 学习审批路径，为每笔申报生成清单、部门日历、时间线和 BPMN。路径和时间由规则引擎计算，模型负责阅读和说明。

### [AI Video Factory](https://github.com/Hydra0529/AI-Video-Factory)

Turns a sentence into a video of up to about one minute. Qwen writes the shot list, Wan2.2 renders each shot, and Celery runs the job in the background.

一句话生成最长约一分钟的短视频。Qwen 负责分镜，Wan2.2 负责图生视频，Celery 在后台渲染。
